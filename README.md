# Smart Pantry Pal

I am building AnnRakshak, a smart food inventory management web app. I already designed the UI in Figma and want to use that existing design rather than create a new one.

The app helps households, restaurants, and commercial kitchens track food inventory, monitor confirmed expiry dates, identify ingredients that should be used first, reduce food waste, and record wasted food and its cost.

I want a polished, responsive dashboard with a forest-green header, warm ivory background, muted sage cards, realistic ingredient photography, inventory cards, a “Use First” section, upcoming expiry timeline, and waste journal.

Please create the project structure and preserve the ability to import my existing Figma design later. Do not replace my intended visual design with a generic template.
